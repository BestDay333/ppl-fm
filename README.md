# PPL FM Tab for PepeLand

Медиацентр PPL FM для PepeLand с локальной загрузкой интерфейса[cite: 1].

## Особенности проекта
* Интеграция вкладки **PPL FM** в шапку сайта `pepeland.net` строго после раздела «Вики»[cite: 5].
* Прямой эфир радиостанции с интерактивным плеером, визуализатором и регулировкой громкости[cite: 3].
* Лента подкастов и новостей, загружаемая из локального источника `news.json`[cite: 2, 5].
* Вкладка профиля с автоматической синхронизацией сессии пользователя, никнейма и аватара[cite: 5].
* Полностью локальные доступные ресурсы расширения для быстрой работы интерфейса[cite: 1].

## Структура файлов
* **`manifest.json`** — конфигурационный файл расширения (Manifest V3) с указанием прав доступа и доступных ресурсов[cite: 1].
* **`content.js`** — основной скрипт содержимого для внедрения элементов управления, роутинга и взаимодействия с DOM страницы[cite: 5].
* **`player.html`** — разметка интерфейса медиацентра, включающая вкладки прямого эфира, новостей, библиотеки и профиля[cite: 3].
* **`news.json`** — файл данных со списком подкастов, описаниями и датами выпусков[cite: 2].
* **`ppl-only-logo-dark.png`** — графический логотип для оформления профиля[cite: 5].
